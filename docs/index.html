01 · Le parti pris

Pourquoi un portfolio façon Windows XP ?

Un recruteur voit des dizaines de portfolios construits sur le même modèle. Je voulais qu'on se souvienne du mien — et surtout que l'interface elle-même prouve un savoir-faire, au lieu de simplement l'annoncer.

  • Mémorable : un univers que tout le monde reconnaît en une seconde, avec une touche d'humour.
  • Exigeant techniquement : barres de titre en dégradé, boutons en relief, volet de tâches, bulles de notification… tout est recréé en CSS et en SVG, sans aucune capture d'écran de Windows.
  • Cohérent avec mon parcours : j'ai commencé à coder parce que je voulais comprendre ce qu'il y avait derrière l'écran de mes jeux et de mes logiciels.
  • Mais professionnel : le contenu reste clair, lisible et orienté recrutement (CV, parcours, projets, contact).
02 · Les langages et outils

Chaque technologie a une raison d'être là.

J'ai volontairement choisi une stack sans framework. Ce n'est pas que je ne sais pas les utiliser (j'utilise React sur d'autres projets) : c'est que pour un site d'une page, ils n'apportent rien — et que du code natif montre mieux la maîtrise des fondamentaux.

index.html
HTML5 sémantique

La structure porte le sens

Pourquoi
Les balises header, nav, main, section, article, aside, time, output décrivent le contenu : les lecteurs d'écran et les moteurs de recherche le comprennent sans effort.
En plus
Données structurées schema.org/Person, Open Graph, et un sprite SVG : toutes les icônes dans un seul bloc, réutilisées avec <use>.
<!-- une icône définie une fois… -->
<symbol id="i-folder" viewBox="0 0 48 48">…</symbol>
<!-- …réutilisée partout, sans requête réseau -->
<svg><use href="#i-folder"/></svg>
css/style.css
CSS3 natif

Tout le thème XP, sans librairie

Pourquoi
Bootstrap ou Tailwind m'auraient obligé à tout surcharger pour obtenir ce rendu. En CSS natif, je contrôle chaque pixel : variables, linear-gradient, radial-gradient, Grid, Flexbox.
En plus
Responsive en deux points de rupture, et respect de prefers-reduced-motion. Même le ciel et les collines sont dessinés en dégradés si l'image ne charge pas.
/* la barre de titre bleue d'une fenêtre XP */
.xp-titlebar {
  background: linear-gradient(180deg,
    #0997ff 0%, #0053ee 8%, #0050ee 40%, #06f 88%);
}
js/script.js
JavaScript ES2022

Des données vivantes, sans framework

Pourquoi
Les API modernes du navigateur suffisent : fetch + async/await pour GitHub, IntersectionObserver pour la navigation, Pointer Events pour déplacer les fenêtres, Web Audio pour les sons.
Sécurité
Toute donnée venant de l'API est échappée avant d'être affichée, et seuls les liens https:// sont acceptés.

Un portfolio qui se met à jour tout seul

Pourquoi
Une liste de projets écrite à la main est périmée au bout d'un mois. Ici, chaque nouveau dépôt public apparaît automatiquement, classé par domaine et par langage.
Contrôle

netlify.toml
Netlify

Hébergement et déploiement continu

Pourquoi
CDN mondial, HTTPS automatique, mise en ligne à chaque git push, et surtout des en-têtes HTTP configurables (sécurité, redirections) dans un fichier versionné — ce que GitHub Pages ne permet pas.
Sans build
Le code en production est exactement celui du dépôt : lisible tel quel par un recruteur.
[build]
  publish = "site"     # seul ce dossier est mis en ligne
  command = ""         # aucune compilation

04 · L'easter egg

Un Démineur en Python, dans le navigateur.

Tapez le code Konami (↑ ↑ ↓ ↓ ← → ← → B A) sur le site, ou cliquez sur la petite mine en bas de page. Derrière ce clin d'œil, il y a un vrai sujet d'architecture : faire dialoguer deux langages.

  • Logique et affichage séparés : Python ne sait pas qu'il tourne dans une page web, JavaScript ne connaît pas les règles du jeu.
  • Un contrat simple : chaque action renvoie l'état complet du plateau en JSON.
  • Fidèle à l'original : premier clic toujours sûr, « accord » sur les chiffres, drapeaux, appui long sur mobile, records sauvegardés, sons synthétisés.

Chargement à la demande

demineur.js injecte Pyodide depuis jsDelivr uniquement à l'ouverture de la fenêtre.

Import du module

minesweeper.py est récupéré, écrit dans le système de fichiers virtuel, puis importé : pyimport('minesweeper').

Appel Python

Chaque clic appelle ouvrir, drapeau ou accord sur l'objet Python.

Rendu JavaScript

Python renvoie un JSON (statut, mines restantes, plateau) que JavaScript transforme en grille.

05 · Qualité

Ce qu'on ne voit pas, mais qui compte.

Un portfolio est souvent le premier code qu'un recruteur regarde. J'ai donc traité les sujets qu'on attend d'un développeur en entreprise.

Accessibilité

  • Sections reliées à leur titre (aria-labelledby)
  • Annonce des projets chargés (aria-live)
  • Navigation 100 % clavier, focus visible
  • prefers-reduced-motion respecté

Référencement

  • Open Graph : bel aperçu sur LinkedIn
  • Données schema.org/Person
  • sitemap.xml, robots.txt, URL canonique
  • Validé dans Google Search Console

Performance

  • Aucune librairie au démarrage
  • Python chargé seulement si on joue
  • Images en loading="lazy", dimensions déclarées
  • Icônes en sprite SVG : 0 requête

Sécurité

  • Content-Security-Policy stricte
  • Anti-clickjacking (frame-ancestors)
  • Données de l'API échappées
  • Aucun secret ni clé d'API dans le code
